# NOOR OPEN SOURCE FACTORY

**365 Days — 365 Useful Windows Tools for Real People**

An open-source product program for practical, independent utilities serving photocopy/print shops, students, office workers and small businesses. The work is guided by Noor Library (مكتبة النور القل) in Collo, Skikda, Algeria.

## Principles

Offline-first by default; no ads, telemetry, compulsory subscriptions or cloud accounts for basic features. Keep customer documents local. Build narrowly scoped tools, test what is actually testable, and be explicit about hardware/platform limitations. No fake daily commits, duplicated repositories or unfinished stable releases.

## Operating cadence

An active daily schedule is configured for 23:00 Africa/Lagos (UTC+1, currently the same local time as Collo, Algeria). The scheduled run resumes this task in **ask-user** mode, so a run may require user confirmation; automatic unattended execution is not guaranteed.
